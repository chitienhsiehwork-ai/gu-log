# 翻譯、引用與改作的著作權邊界

狀態：`familiar`（情境判斷；實作尚未驗證）

## 證據

- 能說明附上出處不等於取得授權：翻譯與改寫屬於改作，要作者同意；評論時在合理範圍內引用是另一回事。
- 自行舉出市場替代的例子：搶先公開的譯本會吃掉原作者在其他語言市場的收入；再延伸到部落客會失去的流量、讀者關係與說法的掌控。
- 一開始把「摘要字數」當成主要判斷，修正後能辨識「照順序一句對一句」的改寫才是變相翻譯，並理解打亂順序仍會算進摘要比例。
- 能說明把文章標成退役不等於下架（全文仍公開），以及公開程式碼庫的歷史紀錄同樣看得到。
