# 去重、候選排序與合併語意

狀態：`learning`

## 證據

- 主動指出合併資料還包含內容整理責任，能區分配對紀錄與群組連線結果。
- 能區分候選集合、必要條件、排序與提示；理解聯集去重、排序分數不等於機率，並要求用完整候選流程評估參數。
- 能指出一次原始回報與一件待處理需求是不同責任；案件如何分界仍在探索，不能當成已定案 schema。
- 對新實作中的 API 型別與欄位仍陌生；既有設計理解不代表已讀懂程式碼。
- 能分辨資料清理時的「去雜訊」與「丟資訊」；理解去識別化的擾動可能破壞等值判斷，能選出可重現又不可逆的替代方式，並分辨哪些下游產物要跟著重產。
- 會質疑沒有依據的硬門檻，堅持標籤只分類、不預判，裁決要看原始資料；能分辨團隊既有用語與自創名，並區分系統意見與事實。
- 理解只看系統判「是」的樣本只能量到抓錯，要看判「不是」的樣本才知道漏掉多少。
