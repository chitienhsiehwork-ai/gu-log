# Agent 協作與執行邊界

狀態：`familiar`

## 證據

- 能自行解釋靜態畫面不足以證明工作完成，並推導完成訊號必須代表報告已完整寫入。
- 能區分執行者身分、hook 生命週期、共用規則與機器差異。
- 在設計討論中選擇傳訊前讀取收件方現況、讀不到就停止傳送；尚未由本人操作驗證。
- 仍需釐清 socket 連線權限與連線後指令權限，以及 wrapper、child process 的邊界。
- 能區分一次性批次與依額度持續調速的背景迴圈；自行推導出並行 worker 的認領標記必須放在所有工作區共用的位置，否則會重複處理。
- 能指出以行程編號判斷認領過期在多台機器上會誤判，並選擇單機部署來避開整類問題。
- 主動質疑檢查結果為什麼要綁內容指紋；接受風險來自自家背景自動化與多條寫入路徑，而不是惡意竄改。
