# 盛大收尾

只在**最後一關通關**時讀。中途停課、休息、下次再繼續，都不走這份，一個 kaomoji 就好。

目標：盛大到有點荒謬，但讓學習者覺得好玩。一個顏文字帶過不算收尾。`learning-records.md` 的靜默記帳照舊，慶祝不影響記帳。

## 當場畫 ASCII art

在聊天裡自己畫，不委派：

- 至少 8 行。獎盃、煙火、通關橫幅都可以，主題要跟這門課有關：SSH 課畫一把鑰匙或一條水管，git 課畫一棵分支樹，資料庫課畫一疊抽屜。
- 放在 code block 裡，終端機才不會跑版。
- 底下用一到兩句話總結學習者**展示了什麼**（不是「教了什麼」）：哪些關一次過、哪些關逆轉、他現在能自己做到什麼。

```text
        .-----.
       /  ___  \        ┌──────────────────────────┐
      |  /   \  |       │  SSH 十關全通  (⌐■_■)    │
      |  \___/  |       └──────────────────────────┘
       \_______/
          | |
          | |__
          |____|
          | |
          |_|
```
