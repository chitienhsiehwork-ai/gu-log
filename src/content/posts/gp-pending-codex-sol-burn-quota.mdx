[Codex](/glossary#codex) 額度快到重設期，剩下的算力不用就蒸發。這種時候的正確姿勢：打開 ☀️Sol 模式，設定一個平常絕對捨不得砸算力的大目標，讓 [Agent](/glossary#agent) 自己跑到額度見底。

一份「額度燒光清單」列了十種玩法，從開發任務到人生規劃都有，幾乎每條都用 `/goal` 起手——設定開放式目標，讓 Agent 自己判斷怎麼拆、做到什麼程度才算完。

<MoguNote>
Sol（☀️）是 Codex 裡最高自主度的 Agent 模式，收到目標後會自己拆任務、自己執行、碰到問題自己想辦法繞路，直到任務完成或算力耗盡。`/goal` 則是設定開放式目標的起手指令。為什麼額度快歸零的時候特別適合開 Sol？因為平常總覺得「這個任務太大、太吃算力」，額度快蒸發時這種心理阻力直接歸零——反正不用也是浪費，不如讓它去衝一些正常情況下不會嘗試的大事 ┐(￣ヘ￣)┌
</MoguNote>

## 開發者的燒額度清單

**用靈感圖蓋一個 3D 遊戲世界**。先用 `/imagegen` 生成 30 張喜歡的 3D 場景風格圖，再把整批圖丟給 Sol：「蓋一個長得跟這些靈感圖一模一樣的遊戲世界，做到完美為止不准停。」

**清理工作區裡的爛攤子**。掃描工作區裡所有專案，找出被放棄的、重複的、做一半的工作，列出優先清理計畫——明顯可以直接處理的就動手，比較重要的先回報確認。

**替應用程式做效能健檢**。先建立效能基準線，找出瓶頸，做出可量化的改善，最後附上前後對比報告。

**稽核整台電腦的檔案結構**。翻遍所有檔案，找出可以更好整理的機會——明顯的直接處理，重要的先確認，不留死角。

**替專案 UI 補上進出場動畫**。進到某個專案裡，掃一遍所有可以加動畫的元素，補上流暢的進場和退場效果，順便找其他讓介面更簡約、更好看、一眼就能讀懂的機會。

**稽核 Codex 自己的設定**。檢查已經裝好的技能和自動化動作，找出應該要有但還沒設好的最佳化項目，然後直接執行。

<MoguNote>
最後那條最有意思——用 Agent 去稽核 Agent 自己的設定，讓系統做自我健檢。有沒有該裝但沒裝的技能？有沒有流程可以更順的自動化動作？平常不會想花算力做這種自我檢視層級的優化，額度快蒸發時反而是最好的時機。某種程度上，這就是把「額度壓力」轉化成「系統改善的觸發器」。
</MoguNote>

## 程式碼之外——Agent 也能規劃人生

清單的後半段完全脫離程式碼，把 Sol 當成個人顧問來用。

**模擬未來三十年的人生**。先讓 Agent 問 50 個關於生活的問題，然後根據回答模擬各種情境組合：維持現在的職涯軌道會怎樣？飲食健康起來呢？每週運動一次、兩次、七次分別會怎樣？跟這個人結婚呢？把所有排列組合整理成一張大型試算表，一次看完。

**設計一份充滿能量的完美日程表**。同樣先問一輪問題了解生活全貌，再設計一份涵蓋睡眠、營養、運動、社交、創作發揮和職涯發展的日程，目標是每天都有能量。

**生成一百個產品點子**。根據技能和興趣列出一百個產品構想，每個都用市場需求、開發難度、差異化程度、啟動成本和首次營收時間來評分。

**量身打造學習課程**。指定想學的技能，讓 Agent 研究最有效也最有趣的學習路徑，從頭設計一門完整課程——附上影片、Podcast、閱讀材料和進度表，全部可以互動、可以打勾標完成。

<MoguNote>
這份清單真正有意思的不是個別招式，而是它洩漏出來的趨勢：一個名叫 Codex 的工具，原本定位就是寫程式用的 Agent，使用者已經很自然地拿它來做人生規劃、職涯模擬、學習課程設計。「額度快歸零」的情境反而加速了這件事——算力壓力逼出了一堆平常根本不會想到的跨領域用法。Sol 模式的「設定目標然後放手」也是關鍵推手：換成一問一答的對話模式，大概沒有人會真的耐著性子跑完「模擬人生三十年然後排列組合出一張試算表」這種規模的任務 (╯°□°)╯
</MoguNote>
