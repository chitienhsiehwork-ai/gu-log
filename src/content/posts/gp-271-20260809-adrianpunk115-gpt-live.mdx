很多人不是不會背單字，是一開口就被搶話。講到一半卡詞、想改口、想重講，對面已經開始糾錯、丟下一串問題——信心碎掉，練兩次就關 App。

口說最稀缺的，從來不是又一本教材，而是有人願意等。真人英文老師得排課、按鐘收費；OpenAI 的新版即時語音，則把這種「等學習者講完」的陪練塞進手機語音鍵。原作者甚至誇它耐心「勝過八成真人英文老師」。

<MoguNote>
原作者喊「英文老師可以回家了」喊得像裁員大會。AI 大概會先搶走口說陪練最磨人的苦工：陪人卡詞、重來、同一句念一百遍。真人英文老師則能少當一點沙包、多做一點教練。畢竟付老師薪水請他站著挨拳，怎麼算都有點浪費。
</MoguNote>

## 為什麼舊式口說軟體一卡就崩

固定輪替式的「AI 英語口說軟體」像沒耐心的客服：講完一句才回一句；一卡頓、一改口、一換話題，就可能搶話、報錯、直接崩。

這套即時語音採**全雙工**：雙方可以同時聽與說，不必等整句講完才輪到自己。卡詞、停頓、改口時它仍能跟上；語速可放慢，也能重複或換成更簡單的說法；不會的詞先切中文問，學會再回英文。居家、通勤、咖啡廳都能練——但背景噪音與長停頓仍可能讓模型搶話。

白話講：它像常在線、不太嫌煩的口說夥伴。凌晨三點、同一句重講很多遍、同一個情境反覆模擬，這類苦工它特別能扛。真正決定練不練得下去的，卻不是語音鍵本身，而是開場有沒有把「誰握麥克風」鎖死。

## 三分鐘鎖模式：一次一題、講完再糾正

入口很單純：ChatGPT 更新到最新版，點輸入框旁的語音按鈕。預設對話卻很容易搶話、即時糾錯、一次丟一串問題——所以每次開練前先貼這段：

```
我是一位大約 B1（中級）程度的中文母語英語學習者。
請當我的口說陪練。請說清楚、不要太快。
一次只問一個問題。
我停頓或犯小錯時，不要打斷我。
只有在我說「我講完了」之後，才開始糾正。
只有在我主動求助時，才使用中文。
```

這段在做一件事：把主動權交回說話的人。複製三秒，後面所有情境、雅思、回顧，都站在同一套節奏上——不必每段再重講「慢慢說、別打斷」。

誰能用？免費方案是精簡版，可練日常與出國口說，額度採 24 小時滾動；付費方案才是完整版，回應更流暢、複雜指令也比較跟得住。先養成開口習慣，免費就夠進場；要狂刷情境或撐雅思深度追問，才比較吃得到付費那一層。

<MoguNote>
先把「全部免費、噪音免疫」那張布條收起來。OpenAI 的[使用說明](https://help.openai.com/en/articles/20001274)寫得很清楚：免費方案只能有限使用精簡版，額度採 24 小時滾動計算；背景噪音和長停頓仍可能讓模型搶話。免費可以進場，還沒拿到無限體力條。「勝過八成真人英文老師」也很有氣勢，只是找不到那份神祕問卷。完整能力還是落在付費方案——想把同一情境狂刷到膩、或把雅思深度追問撐住，才比較吃得到官方[發表文](https://openai.com/index/introducing-gpt-live/)裡那個全雙工的完整樣子。
</MoguNote>

## 出國五關：同一套劇本，只換角色

鎖好節奏之後，出國高頻口說其實就那幾關。通用指令只貼一次，方括號換角色與情境：

```
請扮演【角色】，和我練習【情境】。
請自然但慢慢地說，一次只問一個問題，等我回答後再繼續。
我卡住時，只給一句簡短中文提示，不要直接替我講完。
角色扮演進行中不要糾正；等我說「我講完了」之後，
只挑三個最重要的錯誤，給我更自然的版本，再請我重講一次。
```

| 關卡 | 角色 | 練什麼 |
|------|------|--------|
| 機場全程 | 國際機場工作人員 | 報到、托運、超重、延誤、登機門變更、安檢、行李遺失 |
| 飯店入住 | 櫃台接待 | 訂房、房型、早餐、無線網路、提早入住、延後退房 |
| 餐廳點餐 | 服務生 | 看菜單、描述口味、特殊飲食、點餐結帳 |
| 飯店應急 | 櫃台接待 | 房間故障、衛生問題、求助、換房 |
| 交通問路 | 計程車司機或路人 | 報地址、地鐵公車、旅行時間、臨時改道 |

卡在「行李超重」沒關係：同一關重開、換一種說法、再講一次。稀缺的陪練時間，就這樣變成可重複刷的低壓資源。

若目標是考試，同一套「講完再糾正」也能搬進雅思。第二部分是一分鐘準備、一到兩分鐘獨白——自己練最難，可直接當考官：

```
請扮演雅思口說考官。
給我一張雅思口說第二部分題卡（需要講 1–2 分鐘的題目）。
先給我 1 分鐘安靜準備，再叫我開始。
聽完我的完整回答，中途不要打斷。
我講完後，依流暢度、詞彙、文法、發音評分，每項都以 9 分為滿分。
指出 3 個具體弱點，改寫我最弱的那一句，並請我再說一次。
```

第一、第三部分則改成：一次一題、第一部分問日常、第三部分逼理由與例子；問完五題再給分數區間與三個改進點。每天換題卡、練完自己錄音回放，往往比只看模型糾錯更有用；第三部分別背模板，讓它繼續追問，才逼得出真的在講。

## 真正變強的地方：五分鐘回顧，每次只改三個

光對練不回顧，等於把錯誤練熟。情境結束後用這段收：

```
請像一位能提供具體建議的英文老師，回顧我們的對話。
只找出三個反覆出現的錯誤或不自然說法。
每一項都列出：我的原句、更自然的版本、一句中文短說明。
然後請我把這三句改進版再大聲說一次。
不要給我一長串文法課。
```

每次只改三個，才改得動；跟著念修改後的句子，慢慢磨掉中式英語、語序亂跳、硬塞大詞。這一步原本是付費英文老師最值錢的部分，即時語音現在也能照指令完成。

每天十五分鐘，勝過偶爾爆肝兩小時。原作者建議三個月切法：第一個月只刷五個出國情境；第二個月加入雅思第一部分；第三個月主攻第二部分獨白與第三部分追問，往 6.5–7.0 方向衝。一年若真的天天練，大約九十一小時——不是魔法，是開口次數慢慢累積。

<MoguNote>
原貼文把每天十五分鐘一路算成一年五百小時以上，計算機看到都想申請離職。每天十五分鐘乘三百六十五天，大約是九十一小時；要練到五百小時，平均每天得超過八十分鐘。三個月後能流利出國交流也比較適合當目標，不是保證書。
</MoguNote>

真人課每一分鐘都在跑學費；語音模型則容許停下來、換個說法、整段重開。先把「不敢講」磨成「再講一次」。英文老師不用回家——讓即時語音多扛一點沙包就好。 (◍•ᴗ•◍)
